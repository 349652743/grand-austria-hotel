# 奥地利大饭店 · 局域网 Web 版

2–4 人的非官方私人局域网原型，按《Grand Austria Hotel》2022 零售版基础规则进行七轮对局。中文界面、原版卡图参考、私有手牌、服务端裁定、实时同步、断线重连和自动存档。仅真人联机，无人机模式。

## 启动

需要 **Node.js 24 或更新版本**（使用内置 `node:sqlite`）。应用没有生产 npm 依赖：

```sh
node server.mjs
```

Windows 也可双击 `start.cmd`，或在项目目录执行：

```powershell
.\start.ps1
# 另一实例使用另一端口和默认独立存档
.\start.ps1 -Port 3211
# 前台运行或显式选择专用存档目录
.\start.ps1 -Foreground -DataDir '.\.local\CustomHotel'
```

房主打开 <http://localhost:3210>；其他玩家打开启动日志中的 LAN 地址（`http://<房主局域网IP>:3210`），填写昵称和六位房间码。至少两人且所有人准备后，房主可开始。

- 默认监听 `0.0.0.0:3210`。`PORT`、`HOST`、`GAH_DATA_DIR` 可通过环境变量覆盖。
- 这是受信任局域网应用，不提供 TLS、账户找回或互联网边界防护；**不要直接映射到公网**。
- 主机必须保持开机。素材已本地保存，运行不需外网。
- 启动脚本发现同端口本应用已运行时只显示地址，**不会自动重启或升级它**。

## 操作与规则范围

- 开局逆序选择客人和三间相邻客房，起点为左下角；初始上层客房仍需付费。
- 正常回合先可选接待一位客人，再必须取骰并执行主行动。取骰之后不能补做普通接待；明确奖励获得客人时按奖励处理。
- 可额外送餐、入住、使用员工和领取目标；“结束回合”交给下一玩家。
- “暂缓”只在尚未开始本回合行动时可用，保留行动顺位等待弃骰重掷。
- 原浏览器刷新或掉线后恢复原席位。清除网站数据会丢失凭据。未开局可离席后重新加入；进行中的席位保留。
- 终局保留完整牌局和凭据，不计入 100 个未结束房间的容量限制。

实现 56 位客人、48 名员工、12 张目标卡、12 个皇帝板块；标准随机六员工手牌、所有人相同夜面酒店；骰子强度、蛇形顺序、暂缓重掷、连锁奖励、房间组、皇帝结算和终局计分。

采用新版厨房帮工 5 克朗、Gizia 额外行动而非额外回合、C2 跨两个最高有入住楼层移除等规则。秘书终局自动选择对本玩家得分最高的合法对手员工效果。**不包括** Let's Waltz! 扩展、日面不同酒店、员工轮抽或单人自动机。

详见 [规则实现记录](docs/rules.md) 和 [审查与验证记录](docs/review.md)。测试和规则审查不代表出版社认证，也不证明穷尽了所有卡牌组合。

## 试玩交互与悔棋

- 未准备房间显示对应颜色与条纹，已准备／入住状态另有文字；餐饮名称与色块同时显示。
- 送餐数量使用加减按钮，并显示客人总需求、已送和仍缺。按钮受厨房库存、订单及每次送餐 3 份限制；新获得餐饮直接分配不受厨房 3 份限制。
- 卡面不再叠加重复得分；“放弃此项”需要确认，取消保留草稿。
- 悔棋是本应用的操作辅助，不属于额外的官方规则：只撤销当前玩家本回合最近一步，不连续追溯。抽牌、市场补牌等新信息、暂缓重掷、结束回合或阶段变化后不能撤销；按钮说明原因。
- 悔棋由服务器验证并广播，牌局 revision 继续递增，其他玩家不能替你撤销，服务端私有快照不会发给浏览器。旧存档兼容，但更新前操作没有可恢复快照；新执行的可撤销操作开始记录。

## 文件与存档

- `engine.mjs`：确定性规则引擎，非法命令不改变原状态。
- `server.mjs`：HTTP、身份验证 SSE、原子存档、单写入者锁。
- `public/`：无构建步骤的前端与本地素材。
- `public/assets/sources.json`：素材来源、尺寸、哈希和权利状态。
- 独立克隆默认存档：项目内 `.local/AgentData/GrandAustriaHotel/`；非默认端口加 `-<端口>` 后缀。
- 在含 `AGENTS.md` 和 `wiki/index.md` 的知识库 `repos/` 内，默认存档仍位于知识库的 `.local/AgentData/GrandAustriaHotel/`，保持原部署路径。
- `GAH_DATA_DIR` 可明确覆盖存档目录；不同进程不得共用它。新版本通过操作系统释放的 SQLite 排他锁阻止第二写入者，异常退出后可恢复。
- 存档、浏览器 localStorage 都含席位凭据，**不得上传或分享**；`.gitignore` 排除运行状态、日志、测试产物和凭据文件。

### 从旧版升级

本轮审查修复不自动重启现有服务。旧版没有新写入锁，因此**绝不能在旧服务仍运行时，以相同存档启动新版测试实例**。先安排停机并备份存档，确认旧进程退出，再启动新版。现有存档中的目标条件保持原样；目标编号修正应用于新建牌局，不篡改旧牌局条件。

## 验证

```sh
npm ci
npm test
npm run test:e2e
node tests/session-browser.mjs
node tests/ui-feedback-browser.mjs
node tests/undo-browser.mjs
node scripts/verify.mjs
```

`npm test` 包括规则边界、全部卡牌执行路径、隐藏信息、非法操作原子性、确定性七轮对局、真实 HTTP 对局、单写入者锁、离席撤权和独立部署。测试使用独立临时存档，不访问正式牌局；测试产物留在项目 `.local/tests/`。

浏览器测试使用已有 Chrome，不自动安装浏览器；`GAH_BROWSER` 可指定已有 Chromium 的可执行文件。默认主 E2E 路径为 `C:/Program Files/Google/Chrome/Application/chrome.exe`，其他系统需设置该变量。E2E 使用四个独立浏览器上下文，经 UI 入座、准备、开局及完成首个骰子操作；余下对局经真实 HTTP 执行，并核验四端终局同步、刷新恢复、离线重连和桌面/手机布局，**不是全程逐步 UI 点击**。

本机多浏览器测试不能代替第二台实体设备联机验收；跨实体设备仍待确认。项目不自动调整防火墙或路由器。
