# 规则依据与实现映射

基础依据：[Lookout Retail Edition 2022](https://www.lookout-spiele.de/upload/de_grandaustriahotel.html_GAH_Retail21_Rules_152_EN_WEB.pdf)；原版 PDF 不包含在本仓库，请从出版社链接查阅。下列页码为说明书印刷页码。

| 页码 | 规则 | 实现 |
|---|---|---|
| 4–5 | 2／3／4 人用 10／12／14 骰；10 克朗；四餐饮各一；六员工手牌；逆序选首客；三间相邻初始房 | `createGame`、`setup` |
| 6–8 | 先可选接客，再必须用一骰；按取骰前数量计算；1 克朗增强；6 点模仿 | `act`、`mainEffects` |
| 8–9 | 新餐饮直接送达免费，厨房 1 克朗送至多三份；入住同色或绿色任意房；连锁奖励 | `allocate`、`checkin`、效果队列 |
| 9 | 10 个房间组，每组只触发一次；蓝组得分，红组钱，黄组皇帝声望 | `ROOM_GROUPS`、`occupy` |
| 10–11 | 蛇形顺序、暂缓保留顺位、弃一骰再重掷、全部用完或骰子耗尽结束本轮 | `advance`、`startRound` |
| 11 | 皇帝先按旧轨道得分，再退 3／5／7 格；3+ 奖励、0 惩罚；不能任意选择扣分 | `endRound`、`applyPenalty` |
| 12 | 员工、已入住房间楼层、厨房及克朗、滞留客人 −5；平局比剩余餐饮和钱 | `finalScore` |
| 13–15 | 48 个员工效果；持续效果按实际取走的骰子点数触发 | `STAFF`、`STAFF_EFFECTS`、`staffScore` |
| 16–19 | 56 位客人的奖励；通常可选执行次序，Gizia 额外行动必须在其他入住收益后；回牌库底可选顺序 | `GUESTS`、嵌套效果队列 |
| 19 | 三类目标，每张 15／10／5 三个席位；只能自己回合领取 | `meets`、`claim` |
| 20 | 12 块皇帝奖励／惩罚；手牌惩罚放回牌库底；C2 从两个最高有入住楼层移除 | `EMPERORS`、`applyPenalty` |

客人餐饮、原价及得分由实体卡图逐张核对；56 份餐饮订单还与 Yucata 公开卡牌悬停数据交叉比对，历史核对记录保存在维护者的本地审计档案（不随仓库分发）。未将第三方游戏程序并入本应用。

基础版允许所有人使用相同酒店布局，本实现固定采用这一标准夜面设置。未实现的日面、轮抽与扩展在界面和 README 明确列出；不以虚构或随机数值替代基础卡组。

服务端是唯一的状态写入者。每次命令先深复制并验证，成功后才写入文件和广播；请求带版本号和去重编号。发送给浏览器的数据删除了其他玩家手牌、牌库顺序、随机数状态及其他玩家的三选一私有牌面。
