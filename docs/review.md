# 基础版规则与发布审查记录

审查日期：2026-10-02。规则基准为 [Lookout 官方 2022 零售版规则书](https://www.lookout-spiele.de/upload/de_grandaustriahotel.html_GAH_Retail21_Rules_152_EN_WEB.pdf)。这是非官方实现审查，不是出版社认证。

## 已修正

- 主行动不可通过通用 `skip` 整体跳过；房间主行动至少实际准备一间，剩余强度可以放弃。无合法完成路径的选择原子拒绝。
- 人事经理 #22 可在房间主行动之前或之后雇佣员工。不能仅按当前余额预判：先雇佣免房费员工，或侍童 #35 入住后通过房间组／管理员收入筹款，都是合法路径。有限可完成性检查保留这些路径，同时防止把最后一条准备路径花光或放弃后卡局。
- Gizia #97 的额外行动在其他入住收益及嵌套奖励后执行，避免利用 20 克朗上限改变结算结果。
- 目标编号修正：106＝12 间房、108＝皇帝轨 10、110＝6 组、111＝一种颜色全部入住、112＝2 列。原有 12 条目标条件并未缺失，错误在编号对应。编号依据官方 PDF 空间坐标绑定；渲染中的卡号不可辨认，未声称逐张目读印刷编号。
- 离席后立即断开旧 SSE，清除失效浏览器席位凭据；网络暂时故障不删除有效凭据。
- 不同端口默认存档隔离，同一目录使用操作系统级单写入者锁；损坏存档拒绝启动而不覆盖原文件。
- 终局自动释放活跃房间名额，但完整存档和凭据保留。
- 独立克隆具有自己的运行目录；测试不依赖维护者的知识库目录结构。

- 审读 48 名员工、56 位客人、12 张目标和 12 块皇帝板块；卡图参考与来源独立保留。
- 官方夜面酒店的 20 格颜色、10 个房间组、组奖励、顶层准备得分和皇帝轨 14 格积分已核对。
- C4：有已雇佣终局员工必须弃一张，否则扣 10 分；不是可以任意选择扣分。
- 认证、席位授权、隐藏手牌、请求版本与重放、路径穿越、昵称转义、请求体限制、限流及存档损坏保护均纳入审查。

## 真实执行

从独立源码副本运行 `npm ci --ignore-scripts`、完整测试、浏览器验收与素材校验：

- `npm test`：49/49 通过，含 2、3、4 人真实 HTTP 七轮对局。
- `tests/browser.mjs`：8 项通过；四个浏览器上下文入座、开局与首行动经 UI 完成，后续七轮通过 HTTP 执行并检查各端同步；不是所有动作逐步点击 UI。
- `tests/session-browser.mjs`：离席重新加入、明确 401 凭据撤销、暂时网络故障保留凭据三项通过。
- `scripts/verify.mjs`：104 张卡图的来源与 SHA-256 通过。哈希正确不代表获得素材授权。
- 依赖安装时审计：0 个已报告漏洞；这不代表应用没有任何安全风险。

详细原始日志、修复前失败与审查 JSON 保存在维护者本地审计档案，不含于发布仓库。

## 保留边界

没有穷举所有卡牌组合；准备路径检查只涵盖当前基础版员工效果，加入扩展效果时必须重审。实体第二台设备连入仍待验证。应用面向受信任局域网，不是公网服务。

源码更新不代表运行中服务已升级。旧版未持有新单写入者锁；升级必须先停止旧实例并备份存档，禁止并行共用正式存档。现有目标条件不自动迁移。

素材公开再分发许可未确认；保持私有托管，不随意改成公开仓库。参见 [NOTICE](../NOTICE.md)。
